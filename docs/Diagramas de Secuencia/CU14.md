## Notas y Hallazgos de Diseno

1. **Precision Temporal y Manejo de Errores:** A diferencia del diagrama de comunicacion, el diagrama de secuencia expone explicitamente las bifurcaciones y respuestas de error (como HTTP 400 Bad Request, HTTP 401 Unauthorized o HTTP 403 Forbidden) encapsuladas en fragmentos condicionales `opt`.
2. **Ciclos de Vida y Persistencia:** Todas las consultas SQL (`select`, `select_for_update`, `update`, `insert`) se muestran vinculadas a sus respectivas entidades relacionales, evidenciando las transacciones de lectura y escritura.
3. **Cierre de Ciclo de Auditoria:** Toda mutacion de estado culmina con la insercion formal en la entidad `b:Bitacora` y la emision de un codigo HTTP 200/201 con su correspondiente payload de confirmacion hacia la interfaz de usuario.
